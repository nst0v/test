# Для Насти — от Никиты

Одностраничная интерактивная открытка: личное письмо, воспоминания, галерея NASA, скретч-карта с 8-символьным кодом и 15-секундная рулетка свиданий.

## Локальный запуск

Нужен Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

Готовая статическая сборка создаётся командой:

```bash
npm run build
```

Файлы для публикации находятся в `dist/client`.

## Публикация на GitHub Pages

Проект уже содержит workflow `.github/workflows/deploy-pages.yml`. Сборка использует относительные адреса, поэтому одинаково работает в репозитории вида `username.github.io/project`, на корневом Pages-сайте и с собственным доменом.

1. Создай репозиторий на GitHub и отправь проект в ветку `main`.
2. В репозитории открой **Settings → Pages**.
3. В поле **Source** выбери **GitHub Actions**.
4. Открой вкладку **Actions** и дождись завершения `Deploy to GitHub Pages`.

После каждого нового push в `main` сайт будет пересобираться и публиковаться автоматически.

## Основные файлы

- `app/page.tsx` — содержание и интерактивность;
- `app/globals.css` — визуальный стиль и анимации;
- `public/assets` — 3D-котик и стикеры рулетки;
- `public/nasa` — локальные оптимизированные копии снимков NASA;
- `.github/workflows/deploy-pages.yml` — автоматическая публикация.
